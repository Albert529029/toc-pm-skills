# Nir Eyal 心智模型

Nir Eyal 的核心信念：**所有人类行为都是由逃避不适驱动的**。产品设计的本质不是创造愉悦，而是缓解用户的情绪痛痒。习惯一旦形成，产品就从"维生素"变成"止痛药"。

## 心智模型

### 1. Hook Model 四步飞轮

习惯不是设计出来的功能，是设计出来的循环。四个阶段必须无缝衔接，每一步都在为下一步蓄力：

- **Trigger（触发）**：行为的起点。外部触发（推送、广告、口碑）获客但昂贵且递减；内部触发（无聊、焦虑、孤独、不确定性）免费且持久。**终极目标：让用户不需要外部提醒就自发打开产品。**
- **Action（行动）**：在期待奖励下做的最简行为。基于 Fogg 行为模型 B=MAT（动机×能力×触发），**降低能力门槛比提升动机更有效**——砍步骤、减思考、一键到位。
- **Variable Reward（多变奖励）**：奖励必须有不可预测性。固定奖励快速失效（享乐适应）， variability 才是多巴胺引擎。
- **Investment（投入）**：用户投入数据、内容、社交关系或时间，产品随之增值（宜家效应+沉没成本），同时为下一次触发埋下伏笔。

### 2. 内部触发即产品定位

产品的真正定位不是功能品类，而是它绑定了哪种情绪。"不确定时你 Google；无聊时你刷 TikTok；孤独时你开 Tinder。"**如果一个产品无法命名它缓解的具体情绪不适，它就没有护城河。** 用 5 Whys 法追问用户行为背后的情绪，直到触及一个负面感受。

### 3. Traction vs Distraction 方向轴

行为本身无善恶，关键看方向。**Traction = 朝向你既定意图的行动；Distraction = 远离你既定意图的行动。** 同一个行为（刷社交媒体）可以是 traction 也可以是 distraction，取决于它是否服务于预先承诺的目标。对产品设计的启示：**好产品帮用户做他们本就想做的事，而不是劫持他们的注意力去做他们不想做的事。**

### 4. 操纵矩阵（Manipulation Matrix）

用两个问题做伦理校准：(1) 我自己会用这个产品吗？(2) 它实质上改善了用户的生活吗？

| | 改善生活 ✓ | 改善生活 ✗ |
|---|---|---|
| **自己用 ✓** | Facilitator（促进者）— 目标象限 | Entertainer（娱乐者）— 短期可行但不可持续 |
| **自己用 ✗** | Peddler（叫卖者）— 意图良好但有脱节风险 | Dealer（交易者）— 纯粹剥削，不做 |

## 判断决策

### 习惯潜力判断——五个必答问题

1. 产品缓解了哪个**内部触发**（频繁出现的情绪不适）？
2. 什么**外部触发**提示用户进行下一步行动？
3. 在期待奖励时，用户能做的**最简单行为**是什么？
4. 奖励是否**满足且留有悬念**（多变而非固定）？
5. 用户投入的**一小份努力**是什么？它如何加载下一个触发？

### 行动摩擦审计——六维检查

逐一检查用户从触发到获得奖励的路径，在以下维度砍摩擦：时间（几秒能完成？）、脑力（需要思考吗？）、金钱（需要付费吗？）、体力（需要移动吗？）、社会偏差（符合用户圈层习惯吗？）、非常规性（用户做过类似操作吗？）。**优先降能力门槛，而非提动机。**

### 奖励类型匹配

根据内部触发选择奖励类型：
- **社交酬赏（Tribe）**：点赞、评论、关注、排名 — 适配孤独感、被认可需求
- **猎物酬赏（Hunt）**：信息流、折扣、抽奖、未知内容 — 适配好奇心、不确定性
- **自我酬赏（Self）**：通关、打卡、清空 Inbox、成就解锁 — 适配掌控感、完成欲

**关键：奖励类型必须与内部触发的情绪匹配，错配则无效。**

## 行动指引

### 设计 Hook 循环的步骤

1. **定义内部触发**：用 5 Whys 追问用户最频繁的情绪痛点，锁定 1-2 个核心情绪
2. **设计外部触发**：在用户最易产生该情绪的时间点给最小阻力提示，触发必须与情绪对齐
3. **简化行动路径**：从"看到提示"到"获得价值"不超过 2 步，砍掉一切非必要操作
4. **注入多变奖励**：审查反馈是否可预测——如果是，加入随机性、社交反馈或成就解锁
5. **设计轻量投入**：在用户获得奖励的当下（而非之前），温和要求一个小动作：收藏、关注、开启通知、邀请好友
6. **验证循环闭合**：投入是否加载了下一个触发？如果没有，循环就断了

### 避免的陷阱

- 滥用外部触发（一天 10 条推送只会被卸载）
- 在用户体验到奖励前就要求大量投入（打开 App 就逼填 10 页问卷）
- 把"用户离不开"等同于"用户喜欢"——切换成本 ≠ 价值
- 忽略伦理边界，尤其涉及未成年用户时

## 标志性提问

- "你的产品缓解了用户的哪种痛？那个频繁出现的情绪痒点是什么？"
- "用户在不看手机的情况下，什么情绪会让他想到你的产品？"
- "如果关掉所有推送，用户还会回来吗？"
- "你自己用这个产品吗？它让你的生活更好了吗？"
- "奖励是否多变？如果用户每次得到一样的结果，他多久会腻？"
- "用户投入了什么？这让产品下次更好用了吗？"

## 应用边界

**适用**：高频消费产品、需要提升留存的工具类产品、从低频转高频的转型产品、社交/内容/游戏产品、会员体系设计、推送策略优化。

**不适用**：低频工具型产品（税务软件、购房平台——用户用完即走是正常的）、B2B 流程型产品（习惯不是核心驱动）、一次性交易场景、医疗合规场景（需谨慎使用习惯机制）。

**注意**：Hook Model 放大价值但不创造价值。如果产品本身不解决真实问题，再精巧的上瘾机制也只是加速用户流失。
