# 《上瘾》用户习惯设计方法论

## 核心框架

### 1. Hook Model 四步循环

产品让用户形成习惯的核心机制，每次完整走完四步，下一次循环质量就提升一级。

```
触发(Trigger) → 行动(Action) → 多变奖励(Variable Reward) → 投入(Investment)
      ↑                                                        |
      └────────────────────────────────────────────────────────┘
                          投入加载下一次触发
```

**触发**：行为启动的开关。外部触发（推送/广告/推荐）负责拉新，内部触发（无聊/焦虑/孤独/FOMO）负责留存。终极目标：用户感到某个情绪时，自动打开你的产品——找不到内部触发，产品就永远依赖营销预算续命。用 5 Whys 法追问用户"为什么用"直到底层情绪暴露。

**行动**：触发后用户为获取奖励所做的最简单行为。核心公式：**B = MAT**（行为 = 动机 × 能力 × 触发）。三个要素必须同时在场，但动机波动大、难以控制——因此能力（降低摩擦）是最高 ROI 的杠杆。设计准则：疲惫、分心、低动机用户能否在 5 秒内完成？减少认知负荷优先于增加激励。

**多变奖励**：固定奖励会衰减，不可预测性才激活多巴胺期待系统。三种类型：
- **部落型**（Tribe）：社交认可——点赞/评论/粉丝。案例：Instagram 的互动通知。
- **狩猎型**（Hunt）：信息/资源获取——下一条内容/搜索结果。案例：TikTok 的无限推荐流。
- **自我型**（Self）：掌控感/完成感——升级/连续打卡/清零。案例：Duolingo 的 Streak。

最佳产品同时覆盖两类以上（如邮箱=部落+狩猎+自我）。关键检查：如果用户每次都知道会得到什么，还会来吗？

**投入**：用户在产品中存入价值（内容/数据/关系/声誉/技能），产生两个效果——IKEA效应（用户高估自己参与构建的东西）和加载下一次触发（每发一条 Snapchat 期待回复，每 pin 一张图期待通知）。投入是连接本次循环与下次循环的关键纽带，也是被忽略最多的环节。

### 2. Fogg 行为模型 (B = MAT)

解释单次行为为何发生/不发生的诊断工具。行为=动机×能力×触发，三者缺一不可。

| 要素 | 核心问题 | 设计杠杆 |
|------|---------|---------|
| 动机(M) | 用户想做吗？ | 对愉悦/痛苦、希望/恐惧、社会认同/排斥三类核心动机；昂贵且难持续 |
| 能力(A) | 用户能做到吗？ | 六维简化：时间/金钱/体力/脑力/社会偏差/习惯；**永远先优化这个** |
| 触发(T) | 被提示了吗？ | 火花型(增强动机)、引导型(增强能力)、信号型(提醒)；时机比内容重要 |

**优先级法则**：先降低能力门槛，再考虑增强动机。营销驱动动机的成本是降低摩擦的 10 倍以上。

### 3. 习惯测试 (Habit Testing) 三步流程

用于诊断"为什么用户没形成习惯"的系统方法论。

**Step 1 - 识别 (Identify)**：定义"习惯化用户"标准（多高频次算形成习惯？），用队列分析找出满足标准的人群。基准线：习惯化用户占比 <5% 说明产品有根本问题。

**Step 2 - 编码 (Codify)**：分析习惯化用户的共同行为路径——他们在注册后做了什么？哪个关键动作之后留存率跳升？Twitter 发现"关注 ≥30 人"是留存拐点，这就是 Habit Path。

**Step 3 - 修正 (Modify)**：基于 Habit Path 改造产品——优化新用户引导、调整功能优先级、设计触发时机，让更多人走上同一路径。然后回到 Step 1 重新测量。

## 行动清单

### 设计 Hook 循环的 8 步检查

1. □ 找到内部触发：用户什么负面情绪下需要你的产品？（无聊？焦虑？孤独？不确定？）写出 2-3 个
2. □ 匹配外部触发：在用户最可能产生该情绪的时间/场景投放提示，确保触发与内部状态对齐
3. □ 精简行动路径：从触发到获得奖励，砍掉一切非必要步骤。目标：5 秒内可完成
4. □ 设计奖励变异性：确定主奖励类型（部落/狩猎/自我），引入不可预测性——不要每次都给一样的东西
5. □ 检查奖励匹配度：奖励是否真的缓解了触发时对应的情绪？用户因为孤独打开——给他社交奖励，不是徽章
6. □ 设计投入环节：奖励峰值后立即请求小额投入（收藏/关注/完善资料/打卡），必须在用户"爽"的瞬间下手
7. □ 追踪投入→触发闭环：每项投入必须明确画出回到下一次触发的箭头——发内容→期待回复、加好友→期待动态、设偏好→更准推荐
8. □ 跑道德检验：你自己会用吗？是否实质改善了用户生活？两个都答"是"——继续；有一个"否"——停下来重新设计

### 留存诊断速查

- **用户不来** → 检查触发：内部触发是否成立？外部触发时机是否准确？
- **用户来了不做** → 检查行动：摩擦太大？5 秒测试通过了吗？
- **用户做了不来第二次** → 检查奖励：太无聊/太可预测？奖励类型匹配情绪了吗？
- **用户用了但不回头** → 检查投入：有没有让用户"存东西"？存的东西能否加载下一次触发？

## 决策工具

### 什么场景用哪个框架

| 场景 | 工具 |
|------|------|
| 设计用户留存循环 | Hook Model 四步循环 |
| 诊断"用户为什么不点那个按钮" | Fogg B=MAT 拆解 |
| 诊断"产品留存数据差" | 习惯测试 (Identify→Codify→Modify) |
| 判断该不该做习惯化 | 频率测试：行为是否每周至少一次？不足则放弃 Hook，用转化模型 |
| 检验是否过度操控 | 操纵矩阵：自用测试 + 改善生活测试 |

### 频率门槛

行为频率低于**每周一次**的产品**不可能**形成习惯。法则：如果你卖的是房子/车/保险，放弃 Hook Model，改用高感知价值 + 服务触达策略。

## 常见错误

1. **跳过投入环节**——只做触发→行动→奖励的短循环，没有让用户"存东西"。没有投入就没有转换成本，没有下一次触发。这是最常见的断环原因。
2. **用虚假随机冒充多变奖励**——给随机优惠券/弹窗并不创造渴望，多变奖励的本质是"用户真正在意的东西不可预测地出现"，不是"随机抽奖"。
3. **奖励类型与内部触发错配**——用户因焦虑打开，你给游戏化徽章；用户因孤独打开，你给搜索推荐。奖励必须对症。
4. **在动机上烧钱，不在能力上优化**——花预算买推送和广告拉人回来，但注册流程要填 6 个字段。先砍摩擦，再烧钱。
5. **外部触发轰炸**——每日推送+邮件+短信三轮轰炸，用户卸载。触发是"刚好在需要时提醒"，不是"不管需不需要都来一发"。上下文匹配 = 好服务，不看上下文 = 骚扰。
6. **没有定义"习惯化用户"就开始优化留存**——不知道谁是你的习惯化用户，迭代方向靠猜。先用 Step 1 跑出基准数据。

## 应用边界

### 适用场景
- 高频使用产品（日活/周活）：社交、内容、游戏、教育、健身、效率工具
- 用户有明确情绪痛点且该情绪发生频率高于每周一次
- 存在自然使用场景（如通勤、睡前、等待）可为习惯提供锚点

### 不适用场景
- 低频交易型产品（购房、保险、大件消费）——强制习惯化反而让用户反感
- 纯效率工具（用户想的是"用完即走"，你要优化的是任务完成速度而非停留时长）
- 用户群无统一高频情绪触发点

### 道德边界
Eyal 的操纵矩阵：**自用测试**（你是否愿意用自己的产品？）+ **改善生活测试**（产品是否实质提升用户生活质量？）。两个都"是"= 促进者，放心用；只有一个"是"= 小贩或艺人，谨慎；两个都"否"= 操纵者，停下来。Eyal 在后续著作《Indistractable》中补充：能被 Hook 循环驱动的好习惯（冥想、学语言、健身）和坏习惯（无限刷视频、赌博）使用完全相同的机制——区别仅在于产品为谁创造价值。
