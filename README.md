# ToC 产品经理专家顾问团

## 三人一桌，三书一案

这套 Skill 套装为 C 端产品经理提供跨视角决策支持：

### 三位专家

| 专家 | 一句话价值 |
|------|-----------|
| **Nir Eyal** | 理解用户为什么"停不下来"——习惯设计的底层心理学 |
| **王慧文** | 判断赛道好不好、大不大、什么时候进——美团实战提炼的商业判断力 |
| **Kathy Sierra** | 设计让用户"觉得自己牛逼"的路径——从激活到布道者的阶梯 |

### 三本书

| 书籍 | 一句话价值 |
|------|-----------|
| **《上瘾》** | 用户习惯四步循环的可执行框架 |
| **《设计心理学》** | 交互评审的七大原则和双鸿沟诊断 |
| **《结网》** | 从概念到上线的中国产品实战全流程 SOP |

### 一个总控

**ToC PM 顾问团** 自动路由问题到最合适的专家/方法论，支持三专家评审会模式。

## 使用方式

安装后，直接对顾问团说：

- 路由模式：**"这个 C 端功能要不要做留存机制？"** → 自动匹配 Nir Eyal + 《上瘾》
- 评审会模式：**"三个专家一起评估这个产品方向"** → 并行输出，含共识/分歧/建议
- 单点咨询：**"让王慧文看看这个赛道"**、**"用《设计心理学》评审这个交互"**
